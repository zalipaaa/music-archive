# 🎵 Музыкальный Архив

Консольное приложение на C# для управления и организации музыкальной коллекции.

## ✨ Функциональность

- ✅ **Добавление песен** - сохранение информации о треках (название, исполнитель, альбом, год, жанр, длительность)
- ✅ **Удаление песен** - удаление треков из архива
- ✅ **Просмотр всех песен** - вывод полного списка с ID
- ✅ **Поиск по названию** - поиск песен по названию (частичное совпадение)
- ✅ **Поиск по исполнителю** - найти все песни артиста
- ✅ **Поиск по жанру** - фильтр по жанру музыки
- ✅ **Поиск по году** - поиск песен по году выпуска
- ✅ **Сохранение данных** - автоматическое сохранение в JSON файл

## 📋 Требования

- .NET 6.0 или выше
- Newtonsoft.Json (NuGet)

## 🚀 Установка и запуск

### Клонирование репозитория
```bash
git clone https://github.com/zalipaaa/music-archive.git
cd music-archive
```

### Восстановление зависимостей
```bash
dotnet restore
```

### Запуск приложения
```bash
dotnet run
```

## 🎮 Использование

После запуска приложения появится главное меню с опциями:

```
1. Добавить песню - вводите данные о новом треке
2. Удалить песню - выберите ID песни для удаления
3. Показать все песни - просмотр всех треков в архиве
4. Поиск по названию - введите название или часть названия
5. Поиск по исполнителю - введите имя артиста
6. Поиск по жанру - введите жанр музыки
7. Поиск по году - введите год выпуска
8. Выход - завершить работу
```

## 💾 Формат данных

Данные сохраняются в формате JSON в файл `songs.json`:

```json
[
  {
    "id": 1,
    "title": "Bohemian Rhapsody",
    "artist": "Queen",
    "album": "A Night at the Opera",
    "year": 1975,
    "durationSeconds": 354,
    "genre": "Rock"
  }
]
```
