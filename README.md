# 🎵 Музыкальный Архив

Просто и удобно! Консольное приложение на C# для управления и организации вашей музыкальной коллекции.

## ✨ Возможности

- ✅ **Добавление песен** - сохраняйте информацию о треках (название, исполнитель, альбом, год, жанр, длительность)
- ✅ **Удаление песен** - удаляйте треки из архива
- ✅ **Просмотр всех песен** - полный список вашей коллекции с ID
- ✅ **Поиск по названию** - найдите песни по названию (частичное совпадение)
- ✅ **Поиск по исполнителю** - все песни конкретного артиста
- ✅ **Поиск по жанру** - фильтр по музыкальному стилю
- ✅ **Поиск по году** - найдите песни по году выпуска
- ✅ **Автосохранение** - все данные сохраняются автоматически в JSON файл
- ✅ **Красивый интерфейс** - удобное меню с emoji

## 📋 Требования

- **.NET 6.0** или выше
- Newtonsoft.Json (устанавливается автоматически)

## 🚀 Быстрый старт

### 1️⃣ Установка .NET (если еще не установлен)

Скачайте .NET 6.0 с сайта: https://dotnet.microsoft.com/download

Проверьте установку:
```bash
dotnet --version
```

### 2️⃣ Распакуйте архив

Распакуйте скачанный ZIP архив в удобную папку.

### 3️⃣ Откройте терминал/командную строку

Перейдите в папку проекта:
```bash
cd путь/к/папке/music-archive
```

### 4️⃣ Восстановите зависимости
```bash
dotnet restore
```

### 5️⃣ Запустите приложение
```bash
dotnet run
```

## 💾 Формат данных

Данные сохраняются в файле `songs.json` в формате JSON:

```json
[
  {
    "id": 1,
    "title": "Bohemian Rhapsody",
    "artist": "Queen",
    "album": "A Night at the Opera",
    "year": 1975,
    "durationSeconds": 354,
    "genre": "Rock"
  },
  {
    "id": 2,
    "title": "Imagine",
    "artist": "John Lennon",
    "album": "Imagine",
    "year": 1971,
    "durationSeconds": 183,
    "genre": "Rock"
  }
]
```

## 🆘 Решение проблем

### Ошибка: "dotnet: command not found"
→ Установите .NET SDK: https://dotnet.microsoft.com/download

### Ошибка: "укажите проект или файл решения"
→ Убедитесь, что вы в правильной папке с файлом `MusicArchive.csproj`:
```bash
dir MusicArchive.csproj
```

### Ошибка при сохранении данных
→ Проверьте, что папка проекта не защищена от записи
→ Попробуйте запустить от администратора

### Архив пуст после перезагрузки
→ Проверьте файл `songs.json` - должен содержать ваши песни
→ Если файла нет, он будет создан при добавлении первой песни
